▶ 별첨: 단어 학습 구조 상세 설명
📌 에빙하우스 망각 곡선 적용
사람의 뇌는 새로운 정보를 접한 후 24시간 내에 약 70%를 잊습니다 (Ebbinghaus, 1885). "3일 후 복습" 루틴은 이 망각 곡선의 첫 번째 하강점을 정확히 잡아내는 전략입니다.

🎯 비유: 새 단어를 처음 배우는 건 "모래 위에 발자국 찍기"입니다. 한 번 찍으면 파도에 지워지지만, 3일 뒤 같은 자리를 다시 밟으면 "시멘트가 굳듯이" 장기기억에 자리를 잡습니다. 파닉스를 병행하면 발자국에 라벨(소리)까지 붙이는 셈입니다.

Reference: Ebbinghaus, H. (1885). Über das Gedächtnis. / Nation, I.S.P. (2001). Learning Vocabulary in Another Language. Cambridge University Press.

  • 🟢 매일 루틴 유지 — 가장 결정적 요소
  • 🟢 파닉스 + sight word 병행 (정석 구조)
  • 🟢 3일 복습 루프로 장기기억화 설계
  • 🟢 복습/테스트 주기적 시행
  • 🟢 리딩책 병행 경험 있음
⚠️ 개선 필요 포인트
  • 🔴 Scholastic 지루함 → 문제풀이 느낌
  • 🔴 출력(말하기) 비중 거의 없음
  • 🟡 읽기 비중이 파닉스보다 낮음
  • 🟡 문장 생성 경험 부족
▶ 별첨: 지루함의 원인과 해법
인지 부하 이론 관점 (Sweller, 1988)
반복형 문제집은 "내재적 인지 부하"는 낮지만 "외재적 인지 부하"가 단조롭게 누적됩니다. 뇌는 새로운 자극이 없으면 회로를 끄기 시작합니다.

🎯 비유: Scholastic이 지루해진 건 아이가 나쁜 게 아니라, "같은 도로만 달리는 자동차"처럼 엔진(뇌)이 자동운전 모드로 전환된 겁니다. 리딩책이라는 "새 도로"를 추가하면 다시 엔진이 켜집니다.

Reference: Sweller, J. (1988). Cognitive load during problem solving. Cognitive Science, 12(2), 257–285.

▸ 개편안 (권장)

파닉스+단어 30%

리딩 40% ↑
말하기 10% 신규
🔑
핵심: 파닉스는 단어 해독 도구로 유지하면서, 학습한 단어가 실제 텍스트에서 쓰이는 걸 확인하는 "리딩"으로 무게중심 이동. 말하기는 입력→출력 전환의 시작점.
⏱️ 하루 20분 최적 루틴 (개편안)
0~3분
🌅 워밍업 대화
Hello / How are you? — 짧은 일상 영어 대화로 뇌 깨우기. 오늘 기분, 날씨 등 자유 토픽.
3~8분
📖 파닉스 + 단어 (유지)
2페이지 유지 → 마지막 1분에 "이 소리로 단어 말해보기" 추가 필수
예: ai → rain, train / oa → boat, goat

💡 단어 학습: 오늘의 신규 단어 4개 제시 → 따라 말하기 → 짧게 사용
8~15분
📚 리딩 (핵심 강화 — 가장 중요한 변화)
리딩책 70% + Scholastic 30%
방식: 부모 먼저 읽기 → 같이 읽기 → 아이 혼자 따라 읽기
추천: Bob Books (후반) / ORT Level 1~2 / Step into Reading Level 1

⭐ 3일마다 복습: 이전에 읽은 책 다시 읽기 (유창성 강화)
15~18분
🗣️ 말하기 (신규 추가 — 필수)
패턴 2개 고정: "I see ~" / "It is ~"
하루 3문장만 → 완전 자동화될 때까지
예: I see a cat. / It is big. / I see rain.
18~20분
🎮 마무리 게임
"Show me something red" 찾기 게임 또는 단어 카드 빙고. 끝낼 때 항상 칭찬 루틴 고정.
▶ 별첨: 루틴 설계 원리 상세
왜 이 순서인가? — 학습 준비 모델 (Warm-Up → Input → Output)
인지 과학에서는 뇌가 학습 상태로 전환되려면 "준비 신호"가 필요합니다. 워밍업은 뇌에게 "지금부터 영어 모드야"라고 알리는 시작 버튼입니다.

🎯 비유: 수영 선수가 물에 뛰어들기 전 워밍업을 하듯, 영어 뇌도 준비 운동이 없으면 처음 5분을 낭비합니다. 반면 20분이라는 짧은 시간 안에서 워밍업→파닉스→리딩→말하기 순서는 "기어를 1단부터 차례로 올리는 것"과 같습니다. 급출발 없이 최고 속도에 부드럽게 도달합니다.

Reference: Krashen, S. D. (1982). Principles and Practice in Second Language Acquisition. Pergamon Press. (Input Hypothesis) / Willis, J. (1996). A Framework for Task-Based Learning. Longman.

🎯
단어 목표: 현재 ~450개 → 약 540~560개 (월 90단어 추가)
2
2개월차
문장 이해 + 패턴 확장
파닉스 Level 4 진입 이해 질문 추가 패턴 4개로 확장 단어 누적 ~650개
말하기 패턴 추가: "I like ~" / "This is ~"
리딩 후 이해 질문 도입: "What is this?" / "Is it big?"
단어: 주제별 묶음 학습 (음식, 장소, 감정 등) — 파닉스 소리와 연결 지속
📌
체크포인트: 1개월차 책을 다시 읽었을 때 유창하게 읽히면 성공 신호
3
3개월차
스스로 말하기 + 초등 대비 완성
파닉스 Level 4 완료 3~5문장 연결 말하기 단어 누적 ~750개 초등 상위 20% 기초
목표 출력: 3~5문장 연결 (I see a dog. It is big. I like dogs.)
리딩: Step into Reading Level 2 / ORT Level 3 도전
단어: 사이트워드 200개 완성 목표 + 파닉스 유도 단어 병행
🚀
도달 기준: 책을 보면서 스스로 소리 내어 읽고, 그림 보고 한 문장 이상 자발적으로 말하면 목표 달성
🔤 단어 학습 전략 (파닉스 연동)
💡
전략 핵심: 파닉스를 계속하는 이유 = 단어 해독 자동화. 새 단어를 보자마자 소리를 스스로 뽑아낼 수 있으면, 어휘 습득 속도가 기하급수적으로 올라갑니다.
  • 📌
    하루 4단어 신규 제시 — 파닉스 소리 단위와 연결 (예: Level 3 복모음 "ai" → rain, train, pain, tail)
  • 🔁
    3일 후 복습 — 플래시카드 or 책에서 찾기 게임으로 재습득. 단순 암기가 아닌 맥락 속 확인.
  • 📚
    리딩북에서 만나기 — Bob Books / ORT에서 배운 단어가 등장하면 강조. "어? 이 단어 우리 배운 거야!" 순간이 핵심.
  • 🗣️
    말하기로 출력 — "I see rain." 처럼 오늘 배운 단어를 문장에 넣어 말하면 장기기억 확률 3배 상승.
▶ 별첨: 파닉스-단어-리딩 연동 학습의 과학적 근거
Dual Coding Theory (Paivio, 1971)
언어 정보는 "청각 코드"와 "시각 코드"가 동시에 활성화될 때 훨씬 강하게 기억됩니다. 파닉스(소리) + 리딩(시각 텍스트) + 말하기(운동 출력)의 삼중 연동이 바로 이 원리입니다.

🎯 비유: 단어를 외우는 것만으로는 "그림만 있는 지도"입니다. 파닉스로 소리를 붙이면 "위치가 표시된 지도"가 되고, 리딩에서 만나면 "실제 그 거리를 걸어본 경험"이 됩니다. 말하기로 출력하면 "그 길을 다른 사람에게 설명해준 것" — 이 단계가 되어야 진짜 내 것입니다.

Sight Word의 역할: 파닉스 규칙을 따르지 않는 단어(the, was, said 등)는 통째로 인식해야 합니다. Scholastic 100 Words는 이 불규칙 단어들을 집중 훈련시키는 책으로, 파닉스와 상호보완 관계입니다.

Reference: Paivio, A. (1971). Imagery and Verbal Processes. Holt, Rinehart & Winston. / Adams, M. J. (1990). Beginning to Read: Thinking and Learning about Print. MIT Press.
